# SauceDemo Selenium Automation Framework

Automation testing framework for https://www.saucedemo.com/

## Tech Stack
- Python
- Selenium
- Pytest
- Page Object Model (POM)

## Features
- Login testing
- Logout testing
- Add to cart testing
- Checkout flow testing
- Reusable BasePage
- Explicit waits for stability

pages/
tests/
utils/
